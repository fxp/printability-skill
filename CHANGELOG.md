# Changelog

All notable changes to this project are documented here.

## 0.1.1.0 — 2026-10-28

- Add ten value-focused acceptance cases covering intent-aware geometry, orientation, process constraints, functional failures, and units.
- Add a machine-readable evaluation set with explicit required findings and prohibited overclaims.
- Validate the evaluation schema and status vocabulary in the automated test suite.

## 0.1.0.0 — 2026-10-28

- Add five-axis Printability reporting: geometry, process, function, quality, and evidence.
- Add deterministic STL/OBJ/PLY static geometry auditing.
- Add process profiles for FDM/FFF, resin, powder, and metal workflows.
- Add functional-intent routes covering all 20 publicly listed Hi3D Agent 3D Printing skills.
- Add safety boundaries, report contract, automated tests, and CI.
