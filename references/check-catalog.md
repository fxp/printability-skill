# 检查项分类目录

先判断“对象是什么、要用什么工艺做成什么”，再分类。相同现象在不同意图下可能是阻断、风险或无关项。

## A. 几何门禁

| 检查项 | 默认分类 | 判定与边界 |
| --- | --- | --- |
| 文件无法解析、空对象、无三角面 | 硬阻断 | 无法形成路径；先确认格式和导出是否完整。 |
| NaN/Inf 坐标、越界面索引、零尺度 | 硬阻断 | 属于无效几何/变换；不得依赖切片器猜测。 |
| 单位、缩放、轴向、包围盒 | 可能硬阻断 | STL 没有可靠单位。尺寸错误或所有允许方向均超出成型空间时阻断；否则是待确认项。 |
| 开放边界/非水密 | 依意图 | 封闭实体意图下是几何门禁失败；曲面、花瓶/单壁或切片器显式赋厚模式下转为工艺验证项。 |
| 非流形边/顶点 | 通常硬阻断 | 会产生歧义内外或多于两面共享边。若目标切片器修复，仍保留原始缺陷与修复记录。 |
| 自交、相互穿插、共面重叠 | 证实后通常阻断 | 需要能证明交叉的工具或切片层证据；“看起来重叠”不等于已证实。布尔联合后的有效实体可另行复核。 |
| 退化面、重复面、零面积面 | 风险，可升级 | 少量未必阻止路径，但可能造成洞、内部面或修复副作用；若导致切片缺失则升级为阻断。 |
| 面绕序/实体朝向 | 风险，可升级 | 封闭实体的全局朝向和一致绕序影响内外判断。顶点平滑法线与面绕序不可混为一谈。 |
| 多壳/多组件 | 需要解释 | 合法多件、内腔和嵌件不应自动失败；未知碎片、重叠壳、隐藏内壳或与预期数量不符才是问题。 |
| 孤立顶点、边、微小碎片 | 风险 | 可能被忽略，也可能生成意外小岛/移动路径；核对每个组件与设计意图。 |
| 构建体积与禁区 | 可能硬阻断 | 不只比较 XYZ；还要考虑允许旋转、裙边/筏、支撑、工具头/升降机间隙和机器禁区。 |

## B. 工艺可行性

这些检查不能脱离目标机器/材料配置给出固定通过阈值。

| 检查项 | 主要影响 | 需要的证据 |
| --- | --- | --- |
| 最小壁厚、局部薄片、尖边 | 特征可能被省略、脆弱或透光 | 实际线宽/光斑、层高、材料和层预览；必要时截面测量。 |
| 最小孔、槽、文字、纹理 | 闭合、糊掉、尺寸偏差 | 切片路径与同方向试片。 |
| 悬垂、桥接、首个悬空层、孤岛 | 塌陷或无法起层 | 方向、支撑策略和逐层预览。 |
| 支撑可达与可拆性 | 内部残留、表面损伤、无法清理 | 支撑生成结果、拆卸路径和工具可达性。 |
| 床面接触、重心、高宽比 | 翘边、倾倒、层移 | 首层面积、筏/边、方向和机器运动。 |
| 截面积突变与热收缩 | 翘曲、开裂、尺寸漂移 | 材料、腔体温度、路径和历史打印数据。 |
| 受力相对层方向 | 层间断裂、疲劳 | 载荷路径、方向、材料和结构试验。 |
| 封闭腔、排液/通气/排粉 | 困液、吸盘、困粉、清洁失败 | 工艺专属剖面、孔路连通性、方向和后处理方案。 |
| 多材料/多对象关系 | 冲突、悬空、错误材料 | 3MF 对象语义、装配/布尔关系、耗材映射和层预览。 |

## C. 质量与功能风险

这些项通常不阻止生成路径，但可能让成品不符合用途。

- 三角化分辨率、弦高误差和可见分面。
- 层高导致的台阶纹，曲面相对 Z 轴的表面效果。
- 接缝位置、启停痕、支撑接触痕和桥接下垂。
- 孔、圆柱、薄柱、文字和纹理的方向性误差。
- 象脚、收缩、翘曲和后固化变形。
- 滑动、间隙、压配、卡扣、螺纹、嵌件和密封面的实际配合。
- 仅存在于材质、凹凸、置换或法线贴图中的效果。除非烘焙为可打印几何或明确由彩色/纹理工艺支持，否则不会出现在实体表面。
- 平滑着色、自定义顶点法线和面分组。它们可影响预览，但通常不改变三角形位置和刀路；不要用渲染好看替代几何分辨率检查。

功能要求不能只作为质量备注。若模型涉及装配、活动、配合、容器、流体、外壳、灯具或浮雕，按 [functional-intent-routes.md](functional-intent-routes.md) 选择路由，并单独给出 `functional_validation`。同一模型可以同时命中多个路由。

## D. 修复复核

自动修复不是无损事实。至少比较：

- 包围盒和单位；
- 体积与表面积（仅在指标有意义时）；
- 壳体/对象数量；
- 洞、薄壁、尖角、内腔和装配接口；
- 修复前后切片的层数、缺失特征、支撑与估算材料。

若修复引入布尔合并、封洞、重算法线、删除碎片或网格简化，报告实际动作。原始模型与修复副本分别给结论。
