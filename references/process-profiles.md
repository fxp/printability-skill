# 工艺专属检查

只读取当前目标工艺的章节。未知工艺时保留通用几何结论，并把工艺可行性标为 `unknown`。

## FDM / FFF

- 以实际喷嘴、挤出线宽、层高和薄壁策略判断壁、槽、文字与细柱；不要用“喷嘴直径的固定倍数”替代目标配置的切片结果。
- 检查桥接跨度、悬垂、首个悬空层、孤岛、支撑接口和内部支撑能否拆除。切片器生成了支撑不代表支撑可达。
- 检查首层接触、象脚敏感接口、长直边/大截面翘曲和高瘦件稳定性。
- 功能件检查主要载荷相对层面的方向、孔/柱根部、卡扣循环弯曲和螺纹/嵌件周围壁厚。
- 多色/多材料模型核对对象分配、冲刷/换料结构和不同材料黏结，不把外观分区自动解释为独立实体。

最低证据：匹配打印机、喷嘴、材料和工艺配置的实际切片，逐层检查首层、薄壁、孤岛、支撑与最后封顶层。

## SLA / MSLA / DLP

- 检查每层孤岛、支撑连接、截面积突变和剥离方向；“不需要 FDM 悬垂支撑”不表示树脂件可无支撑打印。
- 中空件检查壳厚、排液孔、通气孔、孔路连通性、清洗可达性和未固化树脂困留。
- 检查凹腔相对成型面的吸盘效应，必要时调整方向、开孔或分件。
- 把支撑触点、后固化收缩/翘曲和透明/精细表面的朝向列为质量风险。

最低证据：匹配树脂、层厚与机器配置的逐层岛屿/支撑预览；中空件还需剖面检查排液和清洗路径。

## SLS / MJF 等粉末床

- 通常不需要传统支撑，但仍要检查最小壁/杆/间隙、薄大面翘曲、热集中和零件间距。
- 中空或晶格件检查排粉孔、粉末流动路径与清理工具可达性；封闭空腔会困粉。
- 套叠和活动组件必须按服务商/机器的实际间隙和逃粉规则验证。

最低证据：目标服务商或机器的材料设计规则、排粉路径复核和构建准备结果。

## 金属增材及其他特殊工艺

把通用网格检查作为入口，不给通用工艺通过结论。LPBF、DED、Binder Jetting 等还涉及热应力、支撑锚固、扫描策略、粉末/烧结收缩和设备安全，必须使用目标供应商/设备的设计规则和仿真/构建准备证据。
